# Hydraulic Maintenance Triage (live demo)

Operator and monitoring dashboards for an anomaly detector + component classifier on the public
UCI hydraulic-systems dataset (CC BY 4.0, Helwig, Pignanelli, Schutze 2015).
Pick a cycle id (0-2204) to see the triage result and draft a work order.
Orders are DRAFTs until a human approves them. Demo data resets when the Space restarts.

Full project, evaluation and LLM agent: https://github.com/jahnavid10/hydraulic-agent
